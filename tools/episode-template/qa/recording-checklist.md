# Recording Checklist — {{EPISODE}}

## 录制前

- [ ] 模式：course / technical / news / podcast
- [ ] Slidev 已在 `http://localhost:3030` 打开（podcast 可只开音频）
- [ ] 浏览器全屏，16:9，无地址栏/书签栏
- [ ] OBS 场景：课件全屏 + 麦克风；音量电平正常
- [ ] 录制备份路径可用；磁盘空间足够
- [ ] 讲稿锚点与页面顺序一致（`check-episode.py` 已通过）

## 录制中

- [ ] 连续录制，不按段重来
- [ ] 口误允许；停顿 2 秒后重念
- [ ] 用 2 秒静音或拍手作为后期切点
- [ ] 按 `[SLIDE: NN]` 翻页；按 `[ANIMATION: name]` 播放视频
- [ ] 不追求完美掐点；后期一刀切

## 录制后

- [ ] 抽帧核对开头/中间/结尾
- [ ] 音画同步；无爆音/长时间静音
- [ ] 视频文件已备份
- [ ] 状态写入 `handoff.md`

> OBS 不是由 AI 调用的工具；未安装/未运行时，本阶段标 `NOT_RUN`。
