M1 · 问题

Attention 要回答什么

当前这个位置，应该从其他位置取多少信息？
  • 每个位置仍有自己的输出。
  • 这个输出由别处的内容按相关性混合而成。
  • 本集追两条线：Q/K/V 的角色；score 如何变成分配。

M2 · Q/K/V

Query、Key、Value 各做什么

Query

我在找什么

当前 token 发出的匹配请求。

Key

我能提供什么

每个 token 摆出的可匹配信息。

Value

我实际被取用的内容

被聚合、被带走的内容。

query 决定和谁匹配；value 决定最后混进来的是什么。

M2 · 同源

Self-attention：Q/K/V 同源

  • 同一排 token 各自提供 query、key、value 三种角色。
  • 单头可看作同一输入的不同投影；本集不展开投影矩阵。
同一输入序列 t1–t4→ QKV

不是三句话；是同一来源的三种表示。

M4 · 缩放

先缩放，再归一化

S / √dk = S / 2

q1 行 [6, 0, 0, 0] → [3, 0, 0, 0]

FACT

方法

除以 √dk 是原文做法。

CLAIM

动机

大分数 → 小梯度；原文用 “We suspect”。

INFERENCE

假设下推导

方差为 dk，依赖独立/零均值/单位方差假设。

M5 · 权重

每一行分数变成一组权重

A = row_softmax(S / √dk)

  • 按行做 softmax；每行非负，和为 1。
  • 行是 query，列是 key。

停在 A；输出留给 M6。

M6 · 输出

从权重矩阵 A 到输出 O

O = A V

v1 = [1, 0] v2 = [0, 1] v3 = [1, 1] v4 = [2, 0]

t1 行

o1 = 0.870 v1 + 0.043 v2 + 0.043 v3 + 0.043 v4

≈ [1.000, 0.0866]

t3 行

o3 = 0.25 (v1 + v2 + v3 + v4)

= [1.000, 0.5000]

每个位置各自得到一个输出向量，不是整句摘要。

M6 · 对比

集中关注与均匀混合

t1 · 权重集中

更像 v1

o1 ≈ [1.000, 0.0866]

t3 · 权重均匀

更像四个 value 的平均

o3 = [1.000, 0.5000]

同一套 V，不同的权重，得到不同的混合；集中/均匀没有哪个更对。

M7 · 边界

本集覆盖什么，不覆盖什么

Q/K/V→ score→ /√dk→ 行 softmax→ A→ O=AV

本集覆盖

  • Q/K/V 角色与同源
  • score → /√dk → 行 softmax → A
  • O = A V

明确不做

  • 多头、mask、位置编码
  • 完整 Encoder–Decoder、训练
  • Q/K/V 投影矩阵展开

单头是教学抽象；toy 数字为 illustrative，不是训练结果。
