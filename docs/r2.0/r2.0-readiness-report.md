## 4. Schema 与 QA 风险结论

详见 [r2.0-schema-qa-gap-report.md](r2.0-schema-qa-gap-report.md)。关键结论：

1. 15 字段定义一致，可以冻结；真实课程仍是 8 列，迁移未执行。
2. `mini_schema.py` 只覆盖 27 个关键字；不支持 `format`、`patternProperties`、`contains`、`dependentRequired`、`unevaluatedProperties`、外部 `$ref` 等；不能声称完整 Draft 2020-12 通过。
3. `jsonschema` 未安装，`ajv` 不在 Slidev runtime；R2.1 需要项目内依赖 + `uv.lock`。
4. 严格 QA 假绿的根因已定位：`check-episode.py:830` 状态聚合、`:945` 返回码、`:403` 无录像不告警、`:828` Reveal build 跳过、`:817` 缺 handoff 只是 warning。
5. 24 项测试覆盖契约 harness，不覆盖完整 Schema、生产双跑、真实运行时、人工 Gate 工具、trace 生成、CSV 迁移、CI、备份。
6. R2 计划区分工具/运行时/内容/迁移，但人工 Gate 记录与校验缺少专门工作包；建议补 R2.5b 或 R2.9a。
