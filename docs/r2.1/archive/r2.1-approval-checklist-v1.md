## 2. D-07 运行时适用性、跳过规则与证据要求（待批准）

### 2.1 适用性

| 模式 | Motion typecheck + probe | Reveal 浏览器加载 | Slidev build + 浏览器 | 说明 |
| --- | --- | --- | --- | --- |
| `course` | **必需**（有 Motion 时） | **必需** | 不适用 | Reveal 是默认课件 |
| `technical` | **必需**（有 Motion 时） | 不适用 | **必需** | Slidev 是默认课件 |
| `news` | 有 Motion 时必需 | 不适用 | 有 Slidev 时必需 | 纯口播新闻可跳过，需批准 |
| `podcast` | 不适用 | 不适用 | 不适用 | 需批准记录 |

### 2.2 跳过规则

1. 跳过必须有 `approvals` 记录：`approval_id`、`scope`、`decision=APPROVED`、`approved_by`、`approved_at`、`notes`。
2. 工具缺失（Chrome/Node/pnpm/ffmpeg/Manim）→ `BLOCKED`，不是 `NOT_APPLICABLE`。
3. 部分证据（只有 typecheck、没有 probe；只有 build、没有浏览器）→ `PARTIAL`/`BLOCKED`，不得 `PASS`。
4. 跳过后 `DELIVERY` 必须列出该维度；不得静默 `READY`。
5. 运行时检查失败 → `FAIL`；不得用静态检查或人工目测替代。

### 2.3 必需证据

| 检查 | 必需证据 |
| --- | --- |
| Motion typecheck | 命令、exit code、typecheck 日志、TS/Node/pnpm 版本、输入文件哈希 |
| Motion probe | `record.html?segment=<name>&probe=1` 的 `durationFrames/fps/seconds` JSON、Chrome 版本、截图 |
| Reveal 浏览器 | 静态服务 URL、页面加载成功/控制台错误、逐页截图、Chrome 版本、输入哈希 |
| Slidev build | 命令、exit code、`dist/index.html` 存在、构建日志、Slidev/Node 版本 |
| 录制 | 文件、sha256、bytes、ffprobe JSON、抽帧、人工验收 |

### 2.4 失败条件

- typecheck 非 0、probe 缺失或与声明偏差超出阈值、浏览器加载失败、build 非 0、截图缺失。
- 任一必需运行时检查未执行 → `BLOCKED`，不能进入 `human.accept`/`deliver`。

## 3. D-09 受影响组件 L2 必跑规则（待批准）

| 变更路径 | L1（必跑） | L2（受影响组件必跑） | 说明 |
| --- | --- | --- | --- |
| `04_motion_src/`、`segments.json` | Schema/结构/链接 | Motion typecheck + probe | 动画代码或时长变化 |
| `03_slides/`、`assets/` | data-slide/资源/泄漏 | Reveal 或 Slidev build + 浏览器 | 课件变化 |
| `01_research/`、`02_scripts/` | Schema/引用/锚点/泄漏 | 仅当 visual 受影响时跑对应 L2 | 纯文本变化不一定需要浏览器 |
| `05_recording/` | manifest/cue/顺序 | ffprobe/录制证据（如有） | 录制包变化 |
| `schemas/`、`tests/contract/` | 契约测试 + 链接 + 泄漏 | 不要求浏览器 | 契约变化 |
| `docs/` only | 链接/泄漏/敏感扫描 | 不要求 | 文档变化 |
| CI/工具代码 | py_compile + 单元 + 链接 | 受影响组件的 L2 | 工具变化 |

规则：

1. L2 只在受影响组件上必跑，不做全量重跑。
2. 完整 clean-room 验证独立执行（手动/定时），不替代受影响组件 L2。
3. L2 失败默认阻断合并；若负责人选择仅警告，必须记录并说明。
4. 路径过滤必须显式；不能用“没检测到变化”跳过必需检查。
